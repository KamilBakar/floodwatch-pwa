FloodWatch PWA
A full-stack flood preparedness and monitoring application developed for KV6025 Contemporary Methods of Software Development.

Tech Stack
React + Vite
PHP REST API
MariaDB/MySQL
Environment Agency Flood Monitoring API
Progressive Web App (PWA)
Features
Search Environment Agency monitoring stations
Save locations linked to monitoring stations
Create preparedness actions
View current monitoring data
Manage locations and actions through CRUD operations
